# Presenton for Claude

Create presentations in Claude with [Presenton](https://presenton.ai). Describe your topic and visual style, and Presenton can generate editable PowerPoint slides, a PDF, PNG slide images, and a shareable preview.

## Install

In Claude, open **Customize → Plugins → Discover**, find **Presenton**, and select **Add**. Open the plugin's **Connectors** tab to connect Presenton.

## Create a presentation

Ask Claude for a presentation, for example:

> Create a five-slide investor update with a clean navy and cream design. Give me an editable PowerPoint and a PDF.

You can also invoke the skill directly with `/presenton:presenton`. If you do not specify a format, Presenton creates PPTX, PDF, and PNG outputs. Claude returns download links and a shareable preview link when the presentation is ready.

Presenton processes the content and images you provide to create your slides. Avoid including credentials, payment details, or confidential information.

## Other compatible agents

The standalone Presenton skill is available on [ClawHub](https://clawhub.ai/presenton/skills/presenton) and [skills.sh](https://www.skills.sh/presenton/skills/presenton).
